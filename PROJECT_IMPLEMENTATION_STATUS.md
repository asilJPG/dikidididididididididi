# 🚀 Трекер реализации функционала DIKIDI UZ

## 🎯 Архитектурный план и текущий статус

### 1. Клиентская часть (Client Experience)
- [x] **Главный маркетплейс салонов и услуг** (`/`):
  - [x] Поиск по названию заведения, адресу и оказываемым услугам.
  - [x] Быстрые фильтры по категориям (Барбершопы, Стрижки/Окрашивание, Маникюр/Педикюр, Брови/Ресницы).
  - [x] Карточки заведений с рейтингом, фото, адресом, списком топовых услуг и ценами в UZS.
  - [x] Навигация в шапке: «Мои записи», «Мастерам», «CRM Салона».
- [x] **Виджет онлайн-записи салона** (`/b/[slug]`):
  - [x] 5-шаговый адаптивный визард (Услуга → Мастер → Дата/Слот → Контакты → Подтверждение).
  - [x] Умный расчет доступных слотов времени через `/api/salons/[slug]/slots` с учетом обедов и существующих визитов.
  - [x] Защита от овербукинга с атомарной проверкой наложения интервалов.
  - [x] Экран подтверждения с кодом брони, деталями визита и кнопкой **«Добавить в календарь (.ics)»**.
  - [x] Прямой переход в личный кабинет «Мои записи».
- [x] **Личный кабинет клиента («Мои записи»)** (`/my-bookings`):
  - [x] Поиск записей по номеру телефона (+998...) с автосохранением в сессию.
  - [x] Разделение на вкладки: **«Предстоящие»** и **«История визитов»**.
  - [x] Детальная информация: услуга, длительность, цена, специалист, точное время UTC+5, контакты салона, кнопка звонка.
  - [x] **Отмена визита клиентом** в 1 клик с освобождением слота времени.
  - [x] **Экспорт в календарь (.ics)** для каждого визита.
  - [x] **Повторная запись** в 1 клик к тому же мастеру в тот же салон.
  - [x] **Отзывы и оценки (1-5 звезд)** после завершения визита с пересчетом рейтинга салона и мастера в БД.

### 2. Бизнес-панель владельца (Business CRM & Management — `/dashboard`)
- [x] **Журнал записей**:
  - [x] Переключение между двумя режимами: **«Карточки»** и **«Интерактивная шахматка (Timeline)»** по часам (09:00 - 20:00) и мастерам.
  - [x] Быстрый календарь (Сегодня, дата, фильтр по конкретному мастеру).
  - [x] Модалка карточки визита:
    - Смена статусов в 1 клик: `Подтвердить`, `В кресле`, `Завершить (Наличные)`, `Завершить (Click/Payme)`, `Отменить`, `Не пришел`.
    - Быстрый звонок клиенту (`tel:`) и просмотр контактов.
  - [x] **Ручное создание записи** администратором (выбор услуги, мастера, даты, времени, клиента и комментариев).
- [x] **База клиентов CRM**:
  - [x] Поиск по имени, номеру телефона и заметкам мастера.
  - [x] Таблица клиентов с подсчетом общего LTV (сумма покупок в UZS) и количества визитов.
  - [x] **Модалка заметок о клиенте**: фиксация предпочтений, насадок для стрижки, чая/кофе, аллергий с сохранением в базу.
- [x] **Управление услугами и сотрудниками**:
  - [x] **Прайс-лист услуг**:
    - Модалка создания новой услуги (название RU, цена в UZS, длительность 15-120 мин).
    - Модалка редактирования существующей услуги.
    - Удаление услуги из базы.
  - [x] **Штат специалистов**:
    - Модалка добавления мастера (ФИО, специализация, личный телефон, ставка комиссии 1-100%).
    - Модалка редактирования мастера.
    - Быстрый переход в настройку графика мастера.
- [x] **Касса, аналитика и расчет зарплат**:
  - [x] Финансовые показатели за день: общая выручка, завершенные визиты.
  - [x] Разбивка выручки по способам оплаты: **Наличные (Naqd)**, **Click & Payme**, **Терминал**.
  - [x] **Автоматическая ведомость зарплат мастеров**:
    - Таблица начислений каждому сотруднику: количество обслуженных клиентов, валовая касса, индивидуальный % комиссии и точная сумма начислений к выплате.
- [x] **Настройки заведения**:
  - [x] Редактирование профиля: название, телефон, город, адрес, ориентир, описание с сохранением через `PATCH /api/salons/[slug]`.
  - [x] Персональная ссылка для Instagram био с кнопкой копирования.
  - [x] Информация по Telegram Mini App и боту.

### 3. Кабинет сотрудника / мастера (Staff Workspace — `/staff`)
- [x] **Персональный кабинет мастера**:
  - [x] Выбор мастера или быстрый вход по привязанному аккаунту с автосохранением.
  - [x] Профиль мастера с отображением ставки, рейтинга и отзывов.
- [x] **Вкладка «Мой день (Записи)»**:
  - [x] Расписание визитов только к данному мастеру на выбранную дату (сегодня/завтра/календарь).
  - [x] Детали клиента: услуга, чек, персональные заметки гостя.
  - [x] Кнопки статуса мастера: «Клиент в кресле», «Завершить визит».
  - [x] Быстрое добавление и редактирование персональной заметки о клиенте.
- [x] **Вкладка «Мой график работы»**:
  - [x] Настройка 7 дней недели (Пн-Вс).
  - [x] Тумблер «Рабочий день» / «Выходной».
  - [x] Настройка времени начала и окончания смены (`HH:MM`).
  - [x] Настройка времени обеденного перерыва (`breakStart` — `breakEnd`).
  - [x] Сохранение графика напрямую через `PUT /api/staff/[staffId]/schedule`.
- [x] **Вкладка «Мой заработок»**:
  - [x] Сводные карточки: чистый заработок мастера за выбранный день, валовая касса выполненных услуг, рейтинг мастера.
  - [x] Детализированный список завершенных визитов с расчетом начисленной комиссии по каждому чеку.

### 4. Новые и расширенные API-эндпоинты
- [x] `GET/PATCH /api/client/appointments` — получение записей клиента по номеру телефона и отмена визита.
- [x] `POST/GET /api/reviews` — отправка отзыва клиентом и пересчет рейтингов салона и мастера.
- [x] `GET /api/staff/[staffId]/stats` — расчет финансовой статистики и записей мастера.
- [x] `PATCH /api/salons/[slug]` — сохранение настроек профиля заведения.
- [x] `POST/PATCH/DELETE /api/salons/[slug]/services` — полный цикл CRUD услуг.
- [x] `POST/PATCH /api/salons/[slug]/staff` — управление мастерами салона.
- [x] `POST /api/customers` — сохранение персональных заметок о клиенте.
