# 💈 DIKIDI UZ — Сервис онлайн-записи и CRM для Узбекистана

Современная платформа для автоматизации сферы услуг и бьюти-бизнеса в Узбекистане. Полный аналог DIKIDI, оптимизированный под реалии узбекского рынка (Telegram Mini App, валюта UZS, локальные шлюзы SMS и платежные системы).

---

## 🏗 Архитектура двух сторон (Two-Sided Platform)

### 1. 💼 Business CRM (Для мастеров и салонов) — `/dashboard`
* **📅 Журнал записей:** Интерактивное расписание на день, статусы визитов (*Новая, Подтверждена, В кресле, Завершена, Отменена*), смена статусов в 1 клик, звонок клиенту или переход в Telegram.
* **👥 Клиентская база:** Полная история визитов каждого гостя, персональные заметки мастера (аллергии, предпочтения, чай/кофе), статистика LTV (сколько сум принес клиент).
* **✂️ Услуги и Сотрудники:** Каталог услуг с ценами в сумах (UZS) и длительностью, мастера с индивидуальными процентными ставками для зарплаты.
* **💰 Касса и Финансы:** Выручка за день, разбивка по типам оплат (Click, Payme, Наличные Naqd), расчет зарплат мастеров.
* **⚙️ Настройки и Продвижение:** Персональная ссылка для Instagram био (`/b/bro-barbershop`), интеграция с Telegram-ботом.

### 2. 📱 Client Booking Widget & TWA (Для клиентов) — `/b/[slug]`
* Открывается как обычный сайт или прямо внутри **Telegram Mini App (TWA)** без скачивания приложений.
* **5-шаговый флоу записи:**
  1. Выбор услуги (с фильтрацией и ценами в UZS).
  2. Выбор мастера (*«Шеф-барбер Азиз»*, *«Барбер Тимур»* или *«Любой свободный мастер»*).
  3. Выбор даты и времени (умный расчет свободных окон с защитой от накладок).
  4. Ввод контактов (имя и номер `+998...`).
  5. Подтверждение и возможность получать напоминания в Telegram.

## 🚀 Быстрый запуск

### 1. Запуск Web-приложения и API (Next.js)
```bash
npm run dev:web
```
Приложение откроется на [http://localhost:3000](http://localhost:3000):
* **Главный портал:** [http://localhost:3000](http://localhost:3000)
* **Панель мастера (CRM):** [http://localhost:3000/dashboard](http://localhost:3000/dashboard)
* **Виджет онлайн-записи клиента:** [http://localhost:3000/b/bro-barbershop](http://localhost:3000/b/bro-barbershop)

### 2. База данных (Prisma Studio)
Для визуального просмотра и редактирования всех таблиц (клиенты, записи, мастера, услуги):
```bash
npm run db:studio
```

### 3. Повторный сброс и наполнение тестовыми данными:
```bash
npm run db:push
npm run db:seed
```
